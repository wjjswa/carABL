# E11 — Damage-First Cascade, CarDD YOLOv8s-seg v2 FULL Fine-tuning

Branch: experiments/e11-cardd-damage-first-cascade-20261107

## Research question

Can a damage-type-first Root improve over E10's part-first Root in final
eight-class damage recognition, especially bumper_scratch?

**Stage 1:** Reuse the same CarDD YOLOv8s-seg v2 source weights and feature
extraction code used in original Experiment 2, via
carrepair.models.yolo_features(cfg, method="full"). This retains layers
through SPPF (YOLOv8s), discards original segmentation head, and installs
Global Average Pooling + a NEW six-class linear classification head. BOTH
the pretrained backbone and the new head are updated by supervised training.
This is explicitly **FULL fine-tuning, NOT frozen linear probing**.

Original eight labels -> six training targets:

| Six-way Root | Original labels |
| --- | --- |
| dent | bumper_dent + door_dent |
| scratch | bumper_scratch + door_scratch |
| glass_shatter | glass_shatter |
| head_lamp | head_lamp |
| tail_lamp | tail_lamp |
| unknown | unknown |

All eight original training labels are used. Keep the group-disjoint original
train/validation/test manifest (1,050 / 229 / 226 images).

**Stage 2:** Load the original completed **E9-B** two-class classifier,
trained on bumper_dent/bumper_scratch versus door_dent/door_scratch using
Majorburn YOLO11 Carparts-Seg weights. Each E11 seed uses the exact matching
E9-B seed's best.pt, unchanged. **E11 does not train another expert.**
Do not confuse the YOLOv8 CarDD Root with the YOLO11 E9-B Expert.
The two models have separate encoders, heads and preprocessing.

**Stage 3:** On the same 226-image eight-class test partition, evaluate:

- Hard: choose the highest-probability six-way root. If Dent or Scratch,
  route to E9-B to choose Bumper or Door. If Glass, Head Lamp, Tail Lamp or
  Unknown, output that class directly.
- Soft: multiply P_root(Dent) or P_root(Scratch) by the E9-B Bumper/Door
  probabilities; direct classes keep their Root probability. This yields
  eight normalised scores. The offline test evaluates both inference
  alternatives. Soft routing runs E9-B on all images so out-of-domain
  expert outputs are weighted by low root Dent/Scratch probabilities.

Examples:

    P(bumper_dent) = P_root(dent) * P_E9B(bumper)
    P(door_scratch) = P_root(scratch) * P_E9B(door)
    P(glass_shatter) = P_root(glass_shatter)

**Important**: The six original CarDD segmentation classes are NOT the
six new E11 image-level labels (for example CarDD's lamp_broken does not
distinguish head/tail, and there is no true unknown rejection). The new
supervised head learns the six E11 classes from Kaggle data.

## Training and reporting protocol

Stage 1: three seeds 0/1/2; original CarDD YOLOv8s v2 checkpoint; 224x224
original Experiment 2 random crop/flip/ColorJitter train transform (evaluation
uses resize); full trainable backbone + head; AdamW; LR 1e-4 backbone,
1e-3 head; batch 32; weight decay 1e-4; cosine annealing; max 300
epochs; early stop on validation Macro-F1 (patience 30, min_delta 0.001).
Save best.pt, last.pt, history.csv, loss/accuracy/F1 curves and held-out
six-class test metrics. Do not select any model using the test set.

Stage 2: uses preexisting same-seed E9-B checkpoints, **no retraining**.
For E9-B inference, apply its original 384x384 padded non-crop transform.
Before evaluating, E11 verifies E9-B task, seed, class order, checkpoint,
completed metrics, source model SHA256, original manifest SHA256, and exact
bumper/door test sample IDs. Refuse mismatched source/splits.

End-to-end outputs on all 226 test images per seed:
- Six-way Root: overall Accuracy/Macro-F1, every class Precision/Recall/F1,
  six-class confusion matrix and predictions.
- Hard/Soft eight-way: Accuracy/Macro-F1, every class Precision/Recall/F1,
  eight-class confusion matrices and predictions.
- Every image: original true label, Root true/predicted class, expert predicted
  part, final hard/soft prediction and correctness; model probabilities.
- Error attribution: wrong Root versus right Root/wrong Expert.
- Diagnostic *oracle Root* accuracy uses ground-truth Root only offline to
  estimate upper-bound error sources; it is NOT a deployable inference score.
- Aggregate across seeds into mean ± sample standard deviation; use exactly
  the same held-out test split as E8/E9-C/E10.

Comparison baselines already obtained (NOT new E11 results):
E8 eight-class accuracy 76.55 ± 2.21%,
E9-C hierarchical 79.94 ± 2.00%,
E10 Hard 78.02 ± 1.11%, E10 Soft 78.17 ± 1.35%.

This E11 setup differs in network source (YOLOv8 CarDD rather than YOLO11
Majorburn), output hierarchy, preprocessing and training compute. Improvements
cannot be attributed exclusively to hierarchy without controlled ablations.

## Scientific limits

- A full eight-class image-label dataset is used for new Root training.
  No region-level damage annotations are inferred.
- 'unknown' is a supervised eighth label in the original dataset. This
  does NOT imply detection of previously unseen real-world damage.
- Root mistakes can still propagate to the final eight-class labels.
- E9-B's 91.97% binary accuracy is conditional on 83 in-domain test
  images. Do NOT report it as 226-image eight-class performance.
- E9-B inference in Soft mode on non-Dent/Scratch images is out-of-domain;
  probabilities are not necessarily calibrated.
- Use Root and final per-class confusion matrices, especially Scratch and
  Bumper Scratch, to determine if damage-first routing improves on E10.
