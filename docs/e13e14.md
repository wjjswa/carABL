# E13-B/C and E14-A/B/C/D — E11-compatible ablations

Branch: `experiments/e13-e14-resolution-foundation-20261107`.

These SIX experiments all predict the identical six-class E11 root labels
`dent, scratch, glass_shatter, head_lamp, tail_lamp, unknown`, then use the
**same pre-existing E9-B seed-matched Bumper/Door expert** to predict the
original eight classes. No expert weights are retrained. There is **no
re-splitting or addition of examples**.

## Experiment definitions

| Variant | Root Backbone | Training | Image processing |
|---|---|---|---|
| E13-B / `e13b` | CarDD YOLOv8s-seg v2 | All Root parameters | Aspect-preserving RGB padding, 384px, horizontal flip |
| E13-C / `e13c` | CarDD YOLOv8s-seg v2 | All Root parameters | Same 384px padding/flip + ±4° rotation, ±4% translation, 0.96–1.04 scale, small colour jitter |
| E14-A / `e14a` | DINOv3 ViT-S/16 | Frozen encoder, train Linear Head | Official local HF image processor at 224px; **one-time cached features**, deterministic train views |
| E14-B / `e14b` | DINOv3 ViT-S/16 | Last 4 blocks + final norm + Linear Head | Official HF processor at 224px; flip/small colour jitter train-only |
| E14-C / `e14c` | DINOv3 ViT-B/16 | Last 4 blocks + final norm + Linear Head | Same as E14-B |
| E14-D / `e14d` | SigLIP2 Base patch16-224 **vision encoder** | Last 4 blocks + final norm + Linear Head | Official HF processor at 224px; flip/small colour jitter train-only |

The contrast between E13-B and E13-C isolates the effect of a *mild* augmentation
after padding; neither uses destructive RandomResizedCrop. E11 used 224px
RandomResizedCrop and remains unchanged as the original baseline.

E14-D is supervised fine-tuning of the SigLIP2 vision encoder; it is **not**
zero-shot text/image classification. E14-A has an ordinary trainable linear
classifier, **not** AGE/DP-BOA online clustering.

## Fixed protocol

- Original manifest: **1050 train / 229 val / 226 test**, grouped and immutable.
- Seeds: **0, 1, 2**.
- 300 max epochs, patience 30; best checkpoint selected by **validation six-class macro-F1**. No test-based checkpoint selection.
- Classification criterion: Cross-Entropy. AdamW with cosine LR schedule.
- Six-class root and final eight-class hard/soft Accuracy, macro-F1,
  precision/recall/F1/support per class, confusion matrices saved per seed.
- Exact test image `id`, `path`, `label`, model prediction, scores and
  root/expert error source preserved. E9-B expert runs on the same 384px padded
  preprocessing as E11.
- The 226-image benchmark has already guided E9–E11 development. Any new result
  on it is **exploratory**, not an independent estimate of real-world generalization.
- DINOv3/SigLIP2 processors provide their own required normalization; CarDD
  continues E11's raw `ToTensor` scaling.

## Design notes

- E13-B is NOT identical to E11 except for resolution: E11 used
  `RandomResizedCrop(224)` and E13-B uses preserve-aspect Padding(384).
- E13-C changes mild augmentation relative to E13-B, no destructive crop.
- E14-B/C and E14-D train only the last four encoder blocks and final norm,
  **not** all backbone parameters.
- E14-A caches deterministic train image embeddings once. It **does not**
  cache augmented samples or backpropagate through the pretrained backbone.
- Re-running on a new node recreates the model from the exact local source
  snapshot and loads the saved trainable parameters. Full-fine-tuned CarDD
  models save complete state incl. BatchNorm statistics.
- For SigLIP2 we use the published vision encoder `Siglip2VisionModel`, not
  the language encoder or zero-shot CLIP prompts.
- The E9-B expert checkpoint is required for every eight-class evaluation.
  Its SHA256, task, seed, class order and test manifest are checked before use.
