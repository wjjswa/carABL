# E8: Majorburn YOLO11 car-parts pretraining -> 7/8-class full fine-tuning

## Protocol

Use the pinned checkpoint at Hugging Face:
https://huggingface.co/Majorburn/yolov11-carparts-seg
revision f26ca7107b40dd9a385ea82fd2fef8a3d6044dc7, file best.pt.

The supplied model is part segmentation, not damage classification. We transfer
its YOLO11 encoder (up to and including C2PSA) but replace the segmentation head
with a freshly initialized image-level classification head. All transferred
backbone parameters and the head are FULLY TRAINABLE. There is no separate
Carparts-Seg training stage and no comparison against other initializations.

Two variants, each using the complete eligible training split:
- 8class: bumper_dent, bumper_scratch, door_dent, door_scratch, glass_shatter,
  head_lamp, tail_lamp and unknown
- 7class: the same seven named classes, excluding unknown in train/val/test

Both use **up to 300 epochs**, seeds 0/1/2, independent output directories under
outputs/e8. Test samples are never added to training and are evaluated after
checkpoint selection. 8class's supervised unknown is not open-world novelty.

Every epoch logs augmented training loss, full deterministic training loss/
accuracy/macro-F1, validation loss/accuracy/macro-F1, the train-validation
generalization gap, and an overfitting warning. Diagnostic warnings are
separate from **early stopping** on validation Macro-F1 after 30 consecutive epochs
without improvement greater than 0.001. Training can finish early, with
300 as the maximum. Save best.pt
(selected only by validation macro-F1) and last.pt (resume state).

## Artemis workflow

IMPORTANT: E6/E7 may still use your existing carABL working directory.
Do not switch the branch under running jobs. Create a second worktree:

    cd /mnt/nfs2/engdes/jw840/carABL
    git fetch origin
    git worktree add /mnt/nfs2/engdes/jw840/carABL-e8 origin/experiments/e8-carparts-pretrain-8class
    cd /mnt/nfs2/engdes/jw840/carABL-e8
    source scripts/artemis_env.sh

The new worktree does not automatically contain the ignored carABL dataset.
Use the EXISTING immutable manifest and images by making a local config copy:

    python - <<'PY'
    import yaml
    with open('configs/e8.yaml') as f:
        config = yaml.safe_load(f)
    config['manifest'] = '/mnt/nfs2/engdes/jw840/carABL/data/prepared/manifest.csv'
    config['data_root'] = '/mnt/nfs2/engdes/jw840/carABL/data/kaggle'
    with open('configs/e8_artemis.yaml', 'w') as f:
        yaml.safe_dump(config, f, sort_keys=False)
    PY

Do NOT reinstall the editable Python package into the shared carabl Conda
environment while E6/E7 are active. Python resolves carrepair from this
worktree when run from its root; existing dependencies are reused. Read-only
input data remain in the original worktree and E8 writes only in the new one.

From the new worktree on a network-enabled login/transfer node, download once:

    python -m carrepair.e8 download --config configs/e8_artemis.yaml

Review trusted source and license (model card: AGPL-3.0). PyTorch .pt files
can contain executable pickle content. Before submitting check:

    OMP_NUM_THREADS=1 python -m pytest -q tests/test_e8.py
    python -m compileall -q carrepair

Dry run, then explicitly submit 6 independent GPU jobs:

    bash scripts/submit_e8.sh --config configs/e8_artemis.yaml
    bash scripts/submit_e8.sh --config configs/e8_artemis.yaml --submit
    squeue -u "$USER"

The launcher requests one GPU, eight CPUs, 32GB, up to 3 days per job;
confirm the local partition limit. Per-job logs are in logs/e8 and job IDs
are saved to logs/e8_submissions.json. Duplicate recorded jobs are skipped.
Do not submit training commands on the login node.

To run a single job inside an allocated GPU session:

    python -m carrepair.e8 train --config configs/e8_artemis.yaml --variant 8class --seed 0
    python -m carrepair.e8 train --config configs/e8.yaml --variant 7class --seed 0

If a job was interrupted, inspect it and use --resume on the same command
only when the configuration, manifest, and pretrained checkpoint are unchanged.
Switching the existing E6/E7 checkout is not necessary.

## Results

Each outputs/e8/{7class,8class}/seedN folder contains training history,
loss/accuracy curves, overfitting warnings, best and last model checkpoints,
per-class precision/recall/F1, test predictions, test confusion matrix and
provenance. The 7-class and 8-class tests have different image sets; their
overall accuracies are not directly matched samples.

Once all 6 tasks succeed:

    python -m carrepair.e8 aggregate --config configs/e8_artemis.yaml
    cat outputs/e8/mean_std.csv
    cat outputs/e8/per_class_mean_std.csv
    tar --exclude='*.pt' -czf carABL_e8_results.tar.gz -C outputs e8

No E8 result figures or metrics are available until Artemis training ends.


## Updated early stopping and resubmission (2026-11-07)

E8 now uses `early_stopping.patience: 30`, `min_delta: 0.001`,
monitor `val_macro_f1`. The first epoch establishes the baseline; after
30 consecutive epochs without a significant improvement over the tracked
reference score, training stops. A true higher best score always updates
`best.pt`, even if below the patience threshold. The run stores patience
state in `last.pt` for genuine resume. Overfitting warnings remain separate.

**Existing Slurm allocations do not adopt new code automatically.**
Do not change the files or output roots used by running jobs. Safest:
create a new `carABL-e8-es` worktree at the updated remote branch,
configure the same external read-only images/manifest, download the
pinned model, verify tests, and submit there. This avoids overwriting
old `carABL-e8/outputs/e8` and avoids accidental resume with a different
training protocol. Cancel old jobs with `scancel` only after confirming
their full job names and IDs with `squeue -u "$USER" -o "%.12i %.50j %.2t %R"`.
Do not cancel E6/E7/E9 jobs by mistake.
